ARCHETYPES ARE NOT FIXED

Your HRBP default is a pattern, not a fixed identity. Patterns shift with awareness and practice. Fixer, Teacher, Rescuer, and Advisor each represent a genuine capability running without a pause built in. Coach represents the pause itself, present and trusted, but Coach has its own shadow too: restraint that overstays its welcome. None of the five is the finish line. Each is a gift that can run without calibration. Where you scored today reflects which pattern runs first under pressure right now. Not where it will run once you've practiced catching it.
